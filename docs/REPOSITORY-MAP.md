# Repository map

- `dist/`: current website, bilingual whitepaper, wallet UI and Studio. CSS, PNG and SVG files here supply the pixel/circuit theme; they are application assets, not old contracts.
- `server/`: authenticated administration, statistics and manual quest review.
- `db/` and `drizzle/`: database schema and migrations.
- `tests/` and `scripts/`: current checks, static preview and hosting build.
- `docs/WHITEPAPER.md` and `WHITEPAPER-zh.md`: readable complete whitepaper editions.
- `docs/index.html`, `404.html`, `CNAME`, `.nojekyll`: root-domain redirect; retain these for GitHub Pages.

## OpenBook

OpenBook references in the current protocol describe only the planned later airdrop and processor tier. No OpenBook sale, mint price, deployed address or old contract is active in this tree.

## Branches and history

The current supported release is the default `main` branch. Older branches and historical commits are not current release artifacts. Their presence in GitHub's branch/history views does not make them part of this release. They have not been force-rewritten or deleted.
