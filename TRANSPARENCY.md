# Transparency

This tree contains current application source and planned protocol parameters. No current production token, circuit factory or mining address exists. Contract addresses will be published when deployment is complete.

Implemented: visual editor and simulator, bilingual website, wallet acknowledgement, server-side social applications, manual owner review and published address eligibility. X API checks are optional and not currently configured. Automated identity/follow/like/repost verification is not implemented.

Open: token deployment, burn factory, permission model, audit, storage/gas bounds, VRAM economy/verifier, burned-parts airdrop treatment, team identity disclosure and jurisdiction review. No audit badge, guaranteed yield or automatic liquidity is claimed.

The 10,000-part team allocation is unlocked and committed to circuits, not sale. Planned team-circuit rewards split 50% liquidity support and 50% operations/development/community, executed manually. This does not establish a token price floor or a levy on users.

Public allocation sell-out would yield 7 ETH gross; expenses and funding runway require separate disclosure. Future VRAM rewards are not assured cash funding.

Application hosting and this GitHub repository are separate deployments. The `docs/` Pages redirect must remain intact. Root-domain HTTPS certificate status requires live verification; this source does not certify it.
